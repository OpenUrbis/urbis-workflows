# 🤝 Guia de Contribuição — Urbis Workflows (Viabiliza UI)

Obrigado por seu interesse em contribuir com a interface do **Viabiliza**!

---

## 🚀 Como Executar Localmente

### 1. Pré-requisitos
- Node.js 20+
- Yarn ou pnpm

### 2. Instalação e Execução
```bash
# Instalar dependências
yarn install

# Configurar variáveis de ambiente
cp apps/web/.env.example apps/web/.env

# Iniciar servidor de desenvolvimento
yarn dev
```

---

## 📋 Padrão de Commits e PRs
- Adote o padrão **Conventional Commits** (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`).
- Execute `yarn lint` e `yarn test` antes de submeter Pull Requests.
